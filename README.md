# 🗳️ Shaikh Ayaz University – Online Voting System (SAU Vote)

> **Web Technology  Project**  
> *Developed by Faraz Hussain *

SAU Vote is a modern, secure, and fully interactive Web Application designed specifically for campus elections at Shaikh Ayaz University. Built with pure **HTML5, CSS3, and JavaScript (ES6)**, it offers real-time vote counting, dynamic analytical progress tracking, duplicate vote prevention, and candidate management.

---

## ✨ Key Features

- **📊 Live Election Analytics:** Dynamic dashboard displaying total votes cast, turnout percentage, leading candidates, and live position counters.
- **🗳️ Interactive Voting Engine:** Patients and students can cast votes with real-time dynamic UI updates and animated progress bar metrics.
- **🔒 Anti-Duplicate Voting Safeguard:** Integrated session logic to prevent multiple vote submissions per session.
- **👨‍💼 Candidate Management Modals:** Full admin panel to dynamically add or delete active election candidates.
- **🎓 Custom SAU University Branding:** Elegant layout featuring official university color scheme (Deep Indigo & Violet hues).
- **⚙️ Admin & Profile Settings:** Built-in settings tab customized for system administrator **Faraz Hussain**.

---

## 🛠️ Tech Stack

- **HTML5:** Structural layout and dynamic form handling.
- **CSS3:** Responsive CSS Grid, Flexbox, smooth modal transitions, and CSS custom variables.
- **JavaScript (ES6):** Real-time vote calculations, DOM manipulation, state locking, and modal events.
- **FontAwesome v6:** Comprehensive election and administration icon set.
